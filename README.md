# JobTracker AI 🚀

Live demo: https://ais-pre-sz4l6u4mt6t5esvj3hptam-718133493363.asia-northeast1.run.app

A modern, web-based job tracking application designed to help job seekers streamline their career search, manage applications, and track interview pipelines with the power of AI.

## 🛠️ Tech Stack

* **Framework/Runtime:** TypeScript, Bun, Vite
* **Backend:** Server-side TypeScript (`server.ts`)
* **Database & BaaS:** Firebase (Firestore rules, configuration, and applet setup)
* **Styling & UI:** HTML5, modern web standards

## 📁 Project Structure

```text
├── src/                      # Source code for the frontend/application logic
├── server.ts                 # Backend server configuration
├── firebase-blueprint.json   # Firebase project blueprint & configuration
├── firestore.rules           # Security rules for Firebase Firestore
├── package.json              # Project dependencies and scripts
├── bun.lock                  # Dependency lockfile
└── vite.config.ts            # Vite bundler configuration
